
# Vendor Revenue Analysis

A Streamlit app for analyzing street vendor transaction patterns and predicting daily revenue.

## Features
- Exploratory Data Analysis (EDA) with visualizations
- Vendor clustering using K-means
- Revenue prediction with multiple ML models
- Association rules mining

## Local Installation
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy to Streamlit Community Cloud
1. Push your code to a GitHub repository
2. Go to [share.streamlit.io](https://share.streamlit.io)
3. Connect your GitHub account
4. Create a new app pointing to your repo
5. Select the main branch and app.py as the entry point
6. Deploy!

## Project Files
- `app.py`: Main Streamlit application
- `requirements.txt`: Dependencies
- `cameroon_vendor_data.csv`: Dataset
- `VendorMining_CT23A13.ipynb`: Original analysis notebook
