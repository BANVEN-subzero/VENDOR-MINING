# 🏪 Vendor Revenue Analysis

A beautiful Streamlit app for analyzing street vendor transaction patterns in Cameroon and predicting daily revenue!

## ✨ Features
- **🏠 Home**: Quick overview of the dataset
- **📊 Exploratory Data Analysis**: Visualizations of revenue patterns
- **🔍 Vendor Clustering**: Group similar vendors using K-means
- **💰 Revenue Prediction**: Predict daily revenue using Gradient Boosting
- **🔗 Association Rules**: Find interesting connections in vendor data

## 🚀 Local Installation
1. Make sure you have Python 3.8+ installed
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the app:
   ```bash
   streamlit run app.py
   ```
